# DESK ASSISTANT

横長のWindows用PWA。大きな日付、アナログ時計、Outlookの今日の予定を表示します。天気、ToDo、見出し、会議参加ボタンはありません。

## 起動
HTTPS上にこのフォルダを配置してください（GitHub Pagesなど）。ローカル開発では `python -m http.server 8000` を実行して http://localhost:8000/ を開けます。

## Outlook接続
1. Microsoft Entra 管理センターでアプリを登録し、**シングルページアプリ (SPA)** として公開URLをリダイレクトURIに設定。
2. Microsoft Graphの**委任されたアクセス許可** `Calendars.Read` を設定。組織のポリシーにより管理者の同意が必要です。
3. アプリ画面の左下の歯車を押し、アプリケーション（クライアント）IDを保存し「Microsoftに接続」。

秘密鍵をブラウザに入力・保存しないでください。イベントはブラウザからGraph APIで取得し、サーバーには保存しません。

## Windowsサインイン時の自動起動
Edgeでサイトを「アプリとしてインストール」し、Edgeのアプリ管理画面で自動起動設定が使える場合は有効にします。ない場合は `Win+R` → `shell:startup` で開いたスタートアップフォルダにインストールしたアプリのショートカットを配置してください。Windowsにサインインした後に起動します。

## 通知の注意
予定の開始10分以内になったとき、アプリが**起動しており**、ブラウザの通知許可がある場合にWindows通知を表示します。アプリ終了時、PCスリープ中、ブラウザによるバックグラウンド抑制時の通知は保証できません。初回の通知許可は歯車を押して行ってください。運用前にWindows実機で検証してください。

## その他
アプリは120秒ごとにOutlook予定を再取得します。過去の予定は薄く、直近の予定は強調して表示。予定件数が多い場合、ウィンドウを広げる必要があります。時計は端末の現在時刻を使用します。

## スタートアップ設定用スクリプト
WindowsのPowerShellで `install-startup.ps1` を実行し、公開URLを入力すると、WindowsのスタートアップフォルダにEdgeのアプリ形式で開くショートカットを作成します。スクリプトは自分のPCで内容を確認してから実行してください。既存のPWAインストールとは別のウィンドウになる場合があります。
